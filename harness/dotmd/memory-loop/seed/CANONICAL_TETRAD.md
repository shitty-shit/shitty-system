## LACES_CASES Architecture

- **LACES (Local Sovereignty):** The absolute ground truth. Mothership desktop,
  MINISFORUM execution node, Obsidian vault, local models (Hermes, Skales).
  Law: Nothing leaves local unless explicitly dispatched.

- **CASES (Cloud Heavy Lifting):** Fast-burning cloud work for high-end reasoning,
  synthesis, strategy. ChatGPT, Claude, Gemini, Perplexity. Law: Cloud is a
  worker, not the archive.

- **The Middle Way:** Local doesn't try to be cloud. Cloud doesn't become source
  of truth. Synthesis maintained through markdown, receipts, and clear promotion rules.

## Core Doctrine: TOKENS = MONEY

Every token has cost: money, latency, cognitive load, context clutter, agent
confusion. Agents must reduce token waste, preserve signal, avoid bloat.
