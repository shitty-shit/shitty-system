Kevin's AI harness · plain-language guide

This is a control room for AI work.

It lets several AI workers use local files, local models, memory, automation, and shared project state.

The important truth: it is powerful, but its parts need one clearer front door.

The basic flow

A chat becomes useful when it leaves a trace.

1 · AskKevin gives an agent a job
→
2 · WorkThe agent reads tools and files
→
3 · Leave proofFiles, tests, renders, or a receipt

A plan is not a result. A result is something you can open, run, inspect, or verify.

The four memory layers

There is not one “AI database.” Each layer has a different job.

Raw chat evidence

Freebuff's SQLite database. This is what was actually said.

IJFW working memory

Short handoffs, decisions, and patterns for the next chat.

Operational state

.state/state.json tracks sessions, goals, and tasks.

Semantic memory prototype

AnythingLLM/LanceDB is designed for searchable long-term recall, but is not yet fully proven.
