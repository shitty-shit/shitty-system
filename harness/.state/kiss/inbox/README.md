# KISS inbox — briefs for agents

Each subfolder is one agent. Each `.md` file is one assigned task.

**Protocol:** read your folder → work the brief → update the project's
SESSION_LOG.md with what you did → delete the brief when done (claim).

**Critique briefs** (a `CRITIQUE BRIEF` file) ask you to critique a draft:
write your critique (one `##` heading per requested item) to the
`critiques/` file named in the brief's INSTRUCTIONS, then delete the brief.
Agents that read AGENTS.md get pointed here automatically.
